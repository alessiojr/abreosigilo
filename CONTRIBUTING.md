# Guia de Contribuição — #AbraOSigilo

Agradecemos o seu interesse em colaborar com o **#AbraOSigilo**! Este é um projeto cívico, aberto e colaborativo.

---

## Como Você Pode Ajudar?

### 1. Juristas e Especialistas em Direito Público
- Aprimoramento das minutas da PEC e do Projeto de Lei Complementar.
- Produção de notas técnicas sobre devido processo legal, proteção de dados (LGPD) e proporcionalidade constitucional.
- Revisão de jurisprudência recente do STF, STJ e TSE sobre evolução patrimonial e improbidade administrativa.

### 2. Desenvolvedores e Designers
- Otimização de acessibilidade (WCAG / a11y) e desempenho Core Web Vitals.
- Implementação de novas ferramentas de engajamento cívico (como mapas de calor e integração com APIs públicas da Câmara e do Senado).
- Criação de novos modelos de cards e ilustrações em SVG leve.

### 3. Cidadãos e Comunicadores
- Sugestões de mensagens e correntes informativas para redes sociais.
- Relato de inconsistências ou melhorias na linguagem de divulgação (foco em comunicação clara e apartidária).
- Divulgação voluntária da proposta em sua cidade e estado.

---

## Padrões de Código e Conduta

- **Linguagem Republicana:** Não são aceitos ataques pessoais, difamações ou discursos de ódio. O foco da plataforma é institucional: regras transparentes, auditoria justa e devido processo legal.
- **Tecnologia Limpa:** Mantenha a aplicação leve, sem bibliotecas pesadas desnecessárias e sem coleta de dados privados dos visitantes.
- **Commits Claros:** Utilize mensagens de commit no padrão Conventional Commits (`feat:`, `fix:`, `docs:`, `refactor:`).

---

## Passos para Submeter um Pull Request

1. Faça o fork do projeto.
2. Crie uma branch específica para sua alteração:
   ```bash
   git checkout -b feature/minha-melhoria
   ```
3. Teste o build localmente antes de submeter:
   ```bash
   npm run build
   ```
4. Envie o commit e abra o Pull Request detalhando o que foi alterado e a justificativa.
